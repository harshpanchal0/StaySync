# StaySync  

StaySync is a full-featured Airbnb-like web application built using **MongoDB**, **Express**, and **Node.js**. It allows users to explore and manage property listings for rentals.   

## 📦 Tech Stack

- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (using Mongoose ODM)  
- **Templating Engine:** EJS (or whichever engine you use)  
- **Deployment:** Render  
- **Other Tools:** dotenv, mongoose, body-parser, express-validator, etc.

---

## ✨ Features

- 🏠 Create, Read, Update, Delete listings  
- 🔍 View all listings on homepage  
- 🔐 User authentication  
- 📁 Image upload  
- 📝 Review system  
- 📦 RESTful API architecture
